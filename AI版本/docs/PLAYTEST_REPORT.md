# 第一章试玩报告（M8）

日期：2026-10-04 ｜ 版本：数据 schema 1（`units.json@1`）｜ 对应：00 M8、05 §4.2 / §5、03 §10

## 1. 方法

- 场景定义：`godot/tools/playtest_scenarios.json`（24 个场景 = 8 关 × 推荐解 / 替代解 / 预期失败）。
- 运行：`godot/tools/run_playtests.gd` 经 `BattleController`（与正式战斗同一路径，含开始前校验）以 1× 跑到结束（上限 60 s），再以 2× 复跑比较结果、时间与 `state_hash`。
- 记录：`docs/playtests/<level>_<recommended|alternative|expected_fail>.json`，字段按 03 §10（关卡版本、部署、指令、倍速、结果、时间、损失、目标生命），`notes` 写场景说明与 2× 复核结论。
- 解锁按"已打到该关"处理（全部条件/选敌/行为可用）；各关仍受本关 `allowed` 约束，所有场景都通过了开始前校验。
- 复现：在 `godot/` 目录运行
  ```
  H:\Godot_v4.7.2\Godot_v4.7.2-stable_win64_console.exe --headless --path . -s res://tools/run_playtests.gd
  ```

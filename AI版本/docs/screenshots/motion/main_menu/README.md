## GIF 里的操作顺序

| 时间 | 操作 | 看点 | 关键帧 |
|---|---|---|---|
| 0–1.4 s | 不动鼠标，「开始」有默认焦点 | 选中态，金边缓慢呼吸 | `01_idle_focus_breathe` |
| 1.4 s | 鼠标移到「设置」 | 「设置」淡入选中态并右移，金边上扫过一道斜光；「开始」失焦淡回普通态 | `02`、`03`、`04` |
| 2.6 s | 按下「设置」 | 底板变暗（pressed 切片），按钮微缩，文字略暗 | `05_pressed` |
| 3.0–3.1 s | 按住移出后松开（不触发） | 鼠标已离开，回到普通态 | `06_released_outside` |
| 3.9 s | 移到「退出」 | 同 1.4 s | `07_quit_hover` |
| 5.0 s | 移到空白处 | 「退出」交还焦点，淡回普通态 | `08_left_to_blank` |

## 设计意图

- **只用 R1 已有的四态切片**（normal / hover / pressed / disabled），不画新图。原来四态之间是跳变，动效把它变成淡入淡出：hover 层盖在底层上淡入，满权重时隐藏底层。
- **选中态要一眼看出（第二版）**：hover 切片与 normal 切片本身差别很小（只有描边由灰变金），所以选中时额外做三件事：
  - 底板提亮 30%；
  - 金色描边与月牙加强 45%，并在此基础上呼吸；
  - 文字明显提亮，整个按钮（底板 + 文字）向右让出 14 px。
  底板和金色分开提亮，金色才不会被推到发白。
- **金色是主角**：着色器按 r − b 的阈值从贴图里取出金色（月牙、描边），不需要额外的遮罩图。光带只在从普通态进入选中态时扫过一次，不循环。
- **按下的手感**：0.06 s 变成 pressed 切片并微缩 1.5%，松开 0.18 s 回弹（back 曲线）。
- **待机很弱**：只有选中的那一个按钮呼吸，周期 2.8 s；其余按钮完全静止。
- **焦点跟随鼠标**：悬停即取焦点、离开即交还，同一时刻至多一个按钮亮；鼠标不在任何按钮上时，按钮全部是普通态。键盘：没有焦点时按上 / 下 / Tab，回到第一个可用按钮（Q-072，已采纳）。
- **disabled 不动**：例如数据错误时的「开始」，状态立即切换，没有任何动效。

## 参数（`godot/data/ui_motion.json`）

主界面三个按钮用 `button_menu` 档（继承通用档 `button`，只列出不同的项）；其余全部按钮自动用 `button` 档（P8-4）。

| 项 | button_menu（主界面） | button（通用） | 说明 |
|---|---|---|---|
| hover_in | 0.16 s，sine / out | 0.14 s | 进入选中（含焦点） |
| hover_out | 0.22 s，sine / in_out | 0.20 s | 回到普通态 |
| press | 0.06 s，quad / out | 同 | 按下 |
| release | 0.18 s，back / out | 同 | 松开回弹，带轻微过冲 |
| press_scale | 0.985 | 0.97 | 按下时以中心缩放；切换按钮的按下常态不缩放 |
| hover_lift | 0.30 | 0.08 | 选中时底板（非金色部分）提亮 |
| hover_boost | 0.45 | 0.30 | 选中时金色常亮加强 |
| hover_nudge_px | 14 | 0 | 选中时整体右移 |
| text_hover_lighten / text_press_darken | 0.55 / 0.10 | 0.25 / 0.10 | 文字提亮 / 压暗比例 |
| sweep | 0.55 s；带宽 110 px | 0.45 s；带宽 60 px | 光带是一次性点缀，不属于状态过渡 |
| breathe | 周期 2.8 s，幅度 0.15 | 幅度 0.10 | 金色亮度在常亮基础上再加 0 ~ 幅度 |
| gold_mask | [0.06, 0.22] | 同 | 金色判定：r − b 的平滑阶跃区间 |
| focus_follows_mouse | true | false | Q-072 |

所有状态过渡 ≤ 0.25 s（10 §1.5 约束 2），可以随时被下一状态打断，不会残留（`test_ui_motion.gd`）。

## 静止态与设计图

`--no-motion` 不挂动效，与设计图的比对和 P5 完全相同。各界面"开启动效、不操作"与"不挂动效"的逐像素对照见 `../static/REPORT.md`。

## 实现

- `scripts/ui/button_motion.gd`（ButtonMotion）：作为按钮的内部子节点挂载，`show_behind_parent`，画在文字下面。按钮自身的样式换成内边距相同的空样式，所以文字位置不变。每帧按按钮的绘制状态求出目标态（焦点按选中处理）。外部代码改按钮样式或文字颜色时，下一帧自动重新接管。
- `assets/shaders/button_sheen.gdshader`：只用 `TIME` 和自身 uniform。
- `UiKit.install_button_motion_hook`（SceneRouter 启动时调用）：任何进入场景树的按钮在帧末自动挂上通用档。flat 按钮、复选框 / 开关、带 meta `no_motion` 的按钮不挂。主界面在此之前先以 `button_menu` 档挂上。

## 2. 每个界面：开启动效、不操作时与不挂动效逐像素比较

| 画面 | 不同像素 | 说明 |
|---|---:|---|
| chapter_start / chapter_end / chapter_detail_completed | 0 | 章节地图节点按钮、顶栏按钮、详情面板按钮 |
| level_01 / level_04 / level_08（局内 HUD + 侧栏指令编辑） | 0 | 含处于按下常态的 1× 切换按钮 |
| main_menu_error | 0 | 「开始」禁用，没有焦点 |
| main_menu | 35 942 | 只有默认焦点的「开始」：焦点即选中，呈选中态（提亮 + 右移 14 px），这是设计本意 |
| settings_overlay | 25 542 | 浮窗遮罩下的「开始」（同上），以及拍摄时系统鼠标恰好停在「退出」上方造成的悬停（与环境有关，不是动效残留） |

结论：动效只在悬停、焦点、按下时改变画面；不操作时，各界面与不挂动效时一致。

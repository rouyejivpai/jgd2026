# 第四关 骸猎犬撤离算法试玩记录（M4，03 §5【待验证算法】）

- 日期：2026-10-04　版本：M4（提交见 git log）　执行方式：脚本复现（`tests/integration/test_level_04_retreat_scenarios.gd`），在第四关地图（12×12，骨桩 (3,3)(8,3)(3,8)(8,8)）上放置单位，30 秒内每步记录猎犬位置
- 指标：方向反转 = 相邻两次移动方向点积 < -0.5 的次数（衡量抖动）；进入障碍 = 猎犬所在格不可走的步数；反咬 = 猎犬发出的普通攻击次数
- 猎犬规则：`[4 格内有威胁且有退路 → 撤离(深度 3)] [射程内有敌 → 攻击最近] [待机]`

## 结论与遗留

1. 撤离算法在四类场景下均稳定（反转 ≤ 1、不穿障碍、结果确定），无需引入随机。
2. **数值问题（待策划，见 QUESTIONS Q-021）**：快速形态移速 4.5 > 猎犬 4.0，"单向追击"也能在约 16 s 内把猎犬磨死（文档预期为追不上）；三名单位全部正面追击也会在约 8.5 s 形成事实包围而获胜。参数扫描：猎犬移速 ≥ 4.5 时单向追击 60 s 内无法获胜，推荐解与两翼包夹仍可胜（约 7.6–9.8 s / 12–23 s）；但三单位正面追击在所有扫描值下都会获胜。
3. 以上为脚本复现，建议在 M8 整理 PLAYTEST_REPORT 前由人工在游戏内再试玩一次（F3 调试层可看猎犬当前规则与路径）。

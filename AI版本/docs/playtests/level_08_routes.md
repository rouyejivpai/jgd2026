# 第八关 骨花母体：正面与绕后两条路线试玩记录（M6）

- 日期：2026-10-04　执行方式：脚本复现（规则见 `tests/integration/test_levels_headless.gd` 中 `l8_frontal_rules()` / `l8_bypass_rules()`），推荐部署：承伤 (3,5)、基础攻击 (3,3)、快速 (3,7)、远射 (2,7)，1× 速
- 记录文件（03 §10 格式）：`level_08_front.json`、`level_08_bypass.json`

## 路线一：正面（全员沿"正面花径"推进，见敌追击）
- 结果：**WIN @ 17.3 s**，阵亡 承伤、远射；核心被毁即结算
- 时间线：0.0 s 两名护卫同时锁定承伤（开局即在 7 格视野内）→ 3.0 s / 8.0 s 花粉两次落在远射头上 → 8.6 s G1、10.0 s G2 倒下 → 10.5 s 远射倒下 → 13.0 s 花粉转向基础攻击形态 → 15.5 s 承伤倒下 → 17.3 s 核心倒下
- 观察：四名单位集火下护卫约 10 秒内倒下，正面硬拼并不困难。文档预期"全员正面推进失败"，实际胜利（已转交数值 AI，Q-028）

## 路线二：绕后（承伤正面原地；快速 + 远射走"北侧藤廊"，基础攻击走"南侧藤廊"）
- 结果：**WIN @ 25.7 s**，阵亡 承伤、远射；G2 存活，核心被毁即胜利（无隐藏目标）
- 时间线：0.0 s 两名护卫锁定承伤 → 3.0 s / 8.0 s 花粉两次落在远射头上 → 10.5 s 远射在藤廊途中倒下 → 11.6 s G1 倒下 → 13.0 s 花粉转向承伤 → 15.5 s 承伤倒下 → 18.0 s / 23.0 s 花粉追着基础攻击形态 → 25.7 s 核心倒下
- 观察：承伤成功把两名护卫钉在正面（护卫从未转向绕后单位）。但远射是开局"最远者"，两次花粉（2×35）在它抵达 (12,9) 之前就把它炸死，绕后火力只剩快速 + 基础攻击，比正面更慢。提示第 3 层"让它保持移动或接受一次 35 伤害"与实测吻合：沿藤廊直线行走时两次落点都命中（远射移速 2，2.5 s 预警内只能走 5 格，半径 2 的落点在直线行进方向上仍会覆盖它）。

## 结论
1. 两条路线均可胜利；核心被毁立即结算、护卫无需清除——验证通过。
2. 数值层面"绕后优于正面"的设计意图在当前数值下不成立（正面 17.3 s 优于绕后 25.7 s），已转交数值 AI（Q-028），建议方向：提高护卫生命/伤害使正面硬拼代价更高，或降低花粉对绕后单位的命中（如花粉选敌改为"最近"之外的规则需策划决定）。
3. 以上为脚本复现，建议 M8 由人工在游戏内各玩一次并用结算面板"导出本局记录"补充。

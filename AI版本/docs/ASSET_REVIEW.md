# 资源审查意见（程序侧 → 资源 AI）

日期：2026-10-04 ｜ 范围：除 BGM 以外的全部资源 ｜ 依据：`docs/04_资源需求.md`、`tasks/资源生产任务包_GPT.md`
检查方式：逐文件脚本检测（尺寸、透明、边距、色晕、音频电平）+ 拼图目检 + 游戏内 1920×1080 实机截图。

**结论**：尺寸、透明、抠图边缘、底边锚点、文件命名全部合格；导入无报错。需要重做的问题集中在：**敌人精灵长得像主角人偶、2 个精灵朝向反了、12 个图标字形错误或互相分不清、背景与障碍格错位且整体偏亮、墙/荆棘道具端段与中段高度不一致、Cinzel-Bold 不是粗体**。

优先级：**P0** 影响玩法可读性或显示错误，必须改；**P1** 风格/一致性，建议改；**P2** 小问题，有余力再改。

## P1 建议修改

### 5. 背景亮度与风格不统一
平均亮度（0–255）：L1 96、L2 76、L3 157、L4 145、L5 115、L6 146、L7 144、L8 156。规格要求阴郁、克制、能叠网格。
- L3/L4/L6/L7/L8 偏亮，程序靠整体压暗才勉强贴合调色板。
- L6、L8 是明亮的卡通配色（大片绿草、蓝天玻璃窗），L5 是平涂、细节很少，与 L3/L7 的写实度不一致；L2 则几乎全黑。
- 要求：统一为暗调、低饱和的绘画质感，平均亮度建议 70–110，同一章节风格一致。

### 6. 章节地图风格（`ui/chapter_map_plain.png`）
现为明亮的绘本风（橙红土地、翠绿植被、粉色花朵、蓝灰石墙），与主菜单关键视觉及整体暗色调明显不搭。要求：保留四区域布局与"无文字"，改为暗旧羊皮纸、低饱和、偏暗的配色。

### 7. 墙/荆棘道具端段与中段不匹配（`assets/sprites/props/`）
| 文件 | 主体高度 |
|---|---|
| `wall_end.png` | 232px |
| `wall_mid.png` | 119px |
| `thorn_end.png` | 153px |
| `thorn_mid.png` | 83px |
因为 cutout 按"最长边 232"缩放，宽的中段被压矮，拼起来端段高高竖起、中段像一道矮路沿。要求：同一组的 end/mid **同高同底线**（可在同一张原图里画出再切）；mid 左右边缘可无缝横向拼接；墙高约 1.2–1.5 格（缩放前约 150–180px）。

### 8. 四形态立绘区分度不足（`sprites/illustrations/`）
五张立绘同脸同发型，这一点合格，但四形态与 doll 几乎只有手臂骨刺不同，不满足 04 §4.5-1"职责剪影不同"：
- `bulwark`：缺"肩背与前臂层叠骨板、肌肉硬化、低姿态佝偻"，体型应明显厚重；
- `swift`：缺"四肢拉长、脊骨外露成骨节、前倾奔跑、长袍化作飘带"；
- Q 版 `bulwark`、`swift` 同理，剪影偏弱。
另外 `witch.png` 主体左右都碰到画布边（宽 768 满幅），请检查骨爪是否被裁，必要时缩小一点。

### 字体（`assets/fonts/`）
- `Cinzel-Bold.ttf` 与 `Cinzel-Regular.ttf` **完全相同**（md5 一致，都是可变字体，默认字重 400）。程序里倒计时、标题用的 Bold 实际不是粗体。要求：换成 Google Fonts 的静态 `Cinzel-Bold.ttf`，或用 fontTools `varLib.instancer` 把可变字体实例化为 wght=700 / wght=400 各一份。
- `unifont-18.0.01.otf`（5 MB）不在规格内，程序也没有引用；许可证为 OFL 可以使用。若有用途请说明，否则移出 `assets/`（否则会被打包进导出版）。

### 规格外文件
`sprites/vfx/burning_title/`、`qu_li_bi_hai/`、`qu_li_bi_hai_alchemy/`（标题动画与 demo 场景、脚本，约 3.9 MB）不在 04 规格内，程序未引用。请说明用途（例如是否要用于主菜单标题）；不用的话移出 `assets/`。

### 音效（`assets/audio/sfx/`）
全部 33 个文件电平合格（峰值 −6.9 至 −13.6 dBFS，无削波），时长符合要求。以下需处理：
| 文件 | 问题 | 要求 |
|---|---|---|
| `amb_wind.wav`、`amb_greenhouse.wav` | 首尾各有约 70ms 淡入淡出，循环播放时每 25–30 秒会出现一次音量下陷 | 做成无缝循环：去掉首尾淡变，尾部与开头交叉淡化后裁齐 |
| `dialogue_advance.ogg` | 开头 74ms 静音，点击后有明显延迟感 | 裁掉开头静音 |

说明：程序侧无法试听，未判断音色是否贴合描述（如 battle_start 是否为钟鸣 + 心跳），请资源方自行试听确认。

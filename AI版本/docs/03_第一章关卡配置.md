## 10. 试玩记录格式（关卡册 9.3）

结算面板"导出本局记录"生成 `user://playtests/<level_id>_<yyyyMMdd_HHmmss>.json`：

```json
{ "level_id": "level_07", "level_version": 1, "data_version": "units.json@1",
  "deploy": { "slot_bulwark": [3,4], ... }, "rules": { "slot_bulwark": [ ... ] },
  "speed": 2, "result": "win", "time": 20.0, "losses": ["slot_striker"],
  "objective_hp": { "P": 46 }, "notes": "" }
```
每关至少保存一份推荐解与一份替代解记录后再冻结数值。

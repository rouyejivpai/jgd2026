## 唯一布局与复用

ui_01 作为唯一坐标基准。ui_01～ui_21 共用标题、计时、重试、1×、2×、暂停、设置、退出、任务、机制说明、预算、开始、清空、提示以及五个卡槽的位置。状态之间只替换标签、数值与内容；固定出场保持五个卡槽，内容为承伤/基础攻击/远射及两个锁定槽，保留第7关背景。详情状态 ui_12～ui_20 全部复用同一弹窗框架。

背景沿用已经批准的低噪声背景；单位、头像、血条轮廓、属性图标和锁定图标复用现有资源。游戏文本字体来自 `project.godot` 的 `NotoSerifSC-Regular.otf`，标题使用项目内 Bold 文件。无字切片避免生成文本进入游戏资源。

## 详情窗

详情窗置于所有 HUD 之上，全屏遮罩覆盖并拦截其他控件。标题、关闭、属性和添加指令保持固定，仅中部指令区滚动并裁切超出内容。∧ 对应现有 ConditionMode.ALL，∨ 对应 ANY，按钮严格位于两条条件之间。预览提供滚轮、与或切换、添加示例行、关闭操作；示例行仅展示滚动容量，不写入游戏存档。

## 管线与检查

批准整图 → 原生绘图工具修改详情整图 → 从 ui_01 与新弹窗提取透明无字稿 → 矩形切图 → 同一坐标和同一字体回拼21个局内状态 → 验收。原生无字提取有重采样，不称其为原整图逐像素无损抠取；矩形切片本身已逐像素验证。

九宫格检查发现过边角被拉伸，已将指令卡切片边距收紧为44像素，保证只伸展平直边。条件符号按钮的默认行高曾超出条件间距，已固定为24像素并重验。

本次交付为素材与可交互回拼预览，未修改 Godot 运行场景、逻辑或当前分支。非局内的章节、主界面与设置整图不属于本次详情/HUD位置修正，保留已批准版本。

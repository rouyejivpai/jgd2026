## 1. 铁律（违反任何一条即为错误）

1. **不发明功能**。文档没写的机制、条件、行为、UI 一律不做。觉得缺了什么，写入 `docs/QUESTIONS.md`（格式见 §6），然后按文档继续。
2. **不改契约**。`scripts/core/sim_types.gd` 的枚举名、JSON 字段名、信号名、文件路径只能追加不能改名。改任何 `data/*.json` 后必须跑 `python tools/validate_data.py`。
3. **模拟核心纯净**。`scripts/sim/`、`scripts/data/` 中不得出现 `extends Node`、`get_node`、`$`、`await`、`randf`、`Time.get_ticks_*`、`Engine.get_frames_per_second`。表现层不得写模拟数据。
4. **数值不进代码**。任何关卡数字、单位数值、文案都来自 JSON。代码里出现 `20.0`、`"守住归途"` 之类即为错误（`SimTypes` 常量除外）。
5. **第七关数据不得改动**（`level_07.json` 带 `_comment` 标记）。其他关卡数值可调，但要在 `docs/CHANGELOG.md` 记一行"改了什么、为什么、试玩结果"。
6. **先测试后宣称完成**。每个里程碑结束必须贴出 GUT 运行输出与 `validate_data.py` 输出；没有输出就不是完成。
7. **静态类型**。所有变量、参数、返回值标注类型；`project.godot` 已开启 untyped 警告，警告视为错误。
8. **中文文案走 strings.json / 关卡 JSON**，UI 代码里不写中文字符串（调试打印除外）。
9. **一次只做一个里程碑**。不提前做后面的事，不"顺手重构"。
10. 不使用《异常》等任何现有游戏的截图或素材；不下载来源不明的资源。字体只用 OFL 字体，音效只用 CC0 或自行合成。

## 4. 常见坑（Godot 4.7 / GDScript）

- `AStarGrid2D`：先设 `region = Rect2i(0,0,w,h)`、`cell_size = Vector2(1,1)`、`diagonal_mode = DIAGONAL_MODE_NEVER`，再 `update()`，然后才能 `set_point_solid`。`get_id_path()` 返回 `Array[Vector2i]`。
- 策划坐标 y 向上，屏幕 y 向下：**只在** `SimTypes.sim_to_screen / screen_to_sim` 两处转换，其他地方不要手写翻转。
- `_physics_process(delta)` 的 `delta` **不要**传给模拟；模拟永远用 `SimTypes.SIM_DT`。
- 典型 JSON 读取：`JSON.parse_string(FileAccess.get_file_as_string(path))`，返回 `Variant`，立即 `as Dictionary` 并判空。JSON 数字都是 `float`，坐标要 `int()`。
- `Array[RuleDef]` 这类类型化数组需用 `Array[RuleDef]` 声明并 `.assign()` 或逐个 `append`，不能直接把 `Array` 赋给它。
- 信号连接用 `signal_name.connect(callable)`；跨场景通信只走 `EventBus`。
- `Tween` 用 `create_tween()`；节点释放前 `tween.kill()`。
- 多次 `queue_free()` 同一节点会警告：UnitView 死亡后置 `is_dying` 标记。
- `Control` 拖拽用 `_get_drag_data / _can_drop_data / _drop_data`；地图上的拖拽改用 `_unhandled_input` + 自绘幽灵。
- `CanvasModulate` 会压暗所有 2D 包括 UI——UI 必须放在独立 `CanvasLayer`。
- 着色器 2D 顶点扰动需 `render_mode` 默认即可；`hint_screen_texture` 用于后期 ColorRect。
- Windows 下 `user://` = `%APPDATA%\Godot\app_userdata\人工神灵 Demo\`。
- 中文路径：命令行 `--path .` 在项目目录内执行最稳。

## 5. 工作方式

- 每个任务：读相关文档段落 → 写代码 → 写/跑测试 → 贴输出 → 记录到 PROGRESS.md。
- 遇到文档之间不一致：**JSON > 01/02 > 03 > 04/05**；记录到 QUESTIONS.md。
- 遇到文档与策划 PDF 不一致：以文档为准（文档是对 PDF 的架构解释），但记录到 QUESTIONS.md 供架构方复核。
- 不要修复"看起来像 bug 但文档明确要求"的行为（例如：条件成立但不可执行时**不**回退到下一条）。

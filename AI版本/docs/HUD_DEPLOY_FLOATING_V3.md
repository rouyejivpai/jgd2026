# 部署HUD · 轻边框 V3

用户指出V2边框厚重、细节噪音多、文字歪曲或出框。本轮只修订部署HUD整图，保持已认可场景与角色素材，不实际拆分。

[查看最终整图](../godot/assets/ui/hud/design_deploy_floating_v3.png) · [完整设计源](../godot/assets/ui/hud/design_deploy_floating_v3.html) · [逐项拼接检查](../godot/tools/_raw/p3/hud_floating_v3/QA.md)

原生图像工具编辑无字装饰，减薄边框、去掉密集金属纹和碎饰；关键控件保留少量炼金曲线、半透明底板、功能色和头像出框。普通文字使用游戏字体，按实际字形包围盒检查水平与垂直边距，不对文本压缩、倾斜或拉伸。

最终输出后检查整图：修正任务说明贴边和阶段文字压住装饰，重新渲染，再进行整图目视复查。仍等待用户判断，不进行新切片或运行接入。本轮未做实机测试。

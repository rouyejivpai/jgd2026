# P6 拼接中缺少的素材（交资源侧补充生成）

用户 2026-10-06：拼接时遇到缺少的素材先记下来，之后交资源侧补充生成。
程序侧现在的做法：缺素材的地方用现有切片拉伸、平面样式（StyleBoxFlat，颜色取自批准整图）或省略。资源到位后把 `assets/ui/<界面>/fit_spec.json`（局内 battle_hud、章节地图 chapter）里对应元素换成切片，重跑 `ui_fit_reference.py` + `apply_ui_manifest.py` 即可，不用改代码。

格式要求同 `assets/ui/unified_low_noise/`：无字透明 PNG，与批准整图同风格。九宫格类请注明四边边距。

版本 1.0 ｜ 2026-10-04 ｜ 机器可读清单：`godot/tools/art_manifest.json`；脚本：`godot/tools/gen_image.py`、`cutout.py`
目标：Demo 画面对标正式版。所有资源由执行方按本文规格**生成或制作**，不得使用《异常》等参考游戏的截图或任何版权不明素材。

## 1. 美术方向（策划案 10.3）

**世界**：西方神秘学 + 炼金术 + 血肉魔幻。腐土平原第一章：枯骨农田、哭墙废墟、猎犬巢穴、骨花温室。
**气质**：阴郁、克制的 body horror；呼吸、蠕动、器官化的术法；不做血浆飞溅的廉价恐怖。
**两套形象**（用户 2026-10-04 确认）：
- **棋盘精灵 = Q 版（chibi）**：约 2.5 头身、大头大眼、剪影清晰、赛璐珞描边加轻微手绘明暗；敌我单位与建筑都用这一套。地图俯视 3/4，精灵取正面偏右的 3/4 视角，向左移动时水平翻转。
- **立绘 = 正常头身**：约 7 头身全身站姿，用于战前对白、结算与后续剧情系统；头像从立绘裁切，保证同一张脸。敌人没有立绘，只有胸像头像。

## 4. 生产管线

### 4.1 AI 绘图批处理（`tools/gen_image.py`，已提供）

```
cd godot
python tools/gen_image.py --list                 # 列出 art_manifest.json 中的条目与状态
python tools/gen_image.py --id striker           # 生成单个（输出 tools/_raw/striker.png）
python tools/gen_image.py --group units          # 生成一组
python tools/gen_image.py --all --skip-existing  # 全部
```
- 读取 `PACKY_API_KEY` 或技能目录 `config.json`。单张 30–120 秒，脚本超时 240 秒。失败打印状态码与响应体，**不重试、不编造**。
- 每个条目可生成多次（`--variant 2`）供挑选；最终选用的文件由 `cutout.py` 处理。

### 4.2 抠图与规格化（`tools/cutout.py`，已提供）

```
python tools/cutout.py --id striker              # 按 manifest 的 kind 自动处理：units→抠图裁边缩放 256；portraits→中心裁切 512；backgrounds→缩放 1536×1024；props→抠图 256
python tools/cutout.py --all
```
- 抠图：先按品红色 `#FF00FF` 色键（容差 60），再用 `rembg` 兜底精修边缘；输出前做 1px 边缘去色晕。
- 失败标准：抠图后不透明像素占比 < 8% 或 > 85% 视为失败，脚本报错，需重生成。

### 4.3 程序化贴图（`tools/make_procedural.py`，执行方编写）

按 §2.5、§2.6 的尺寸与形状用 PIL 绘制；所有输出带 alpha；运行一次生成全部。

### 4.4 导入设置（`.import`，在编辑器中设置或用 `tools/apply_import_presets.py` 写入）

| 目录 | compress/mode | mipmaps | filter |
|---|---|---|---|
| backgrounds/ | VRAM Compressed (2) | on | Linear |
| sprites/units、props、portraits | Lossless (0) | on | Linear |
| sprites/ui、vfx、projectiles | Lossless | off | Linear |
| icons/*.svg | — | — | `svg/scale = 2.0` |

### 4.5 验收标准（美术）

1. 四个己方形态一眼可辨"同一人偶的不同变体"；承伤/远射/快速/基础的职责剪影不同。Q 版精灵与对应立绘是同一角色（发型、眼睛、袍色一致）。
2. 敌我在无色环境（灰度截图）下仍可通过底座形状与生命条形状区分。
3. 1080p 全屏时单位边缘无白边/色晕；背景无明显 AI 伪影（多指、文字、重复纹理）。
4. 爆炸预警、受击、死亡、解锁、目标拾取各有独立且清楚的视觉反馈。
5. 所有 AI 生成图均保留原始 1024/1536 文件于 `tools/_raw/`（不入库），便于重做。

# 关卡配置器使用说明（数值策划 / 程序）

配置器统一编辑 `godot/data/teaching.json`，里面记录的是对各关的覆盖值，关卡原文件（`data/levels/*.json`）不会被修改。游戏运行时自动套用这些覆盖值，所以导入后正式游戏立即生效。

## 打开

在工程里运行游戏，任选一种：

- 停在主菜单时按 **F10**。
- 命令行：`H:\Godot_v4.7.2\Godot_v4.7.2-stable_win64.exe --path "<工程>\AI版本\godot" -- --config-editor`
- Godot 编辑器中打开 `res://tools/config_editor.tscn`，按 F6。

配置器是开发工具，导出的 exe 里没有。

## 界面

左侧是关卡列表，按现有编号排列。列表里标注的含义：

| 标注 | 含义 |
|---|---|
| 引导 | 这关配了新手引导 |
| 覆盖 | 这关有被改过的数值或文案 |
| 测试 | 这关的内容是开发期测试内容 |

右侧四页：

| 页 | 能改什么 |
|---|---|
| **关卡配置** | 出场预算、人数上下限、可用形态、信标价格和每包数量；部署区矩形和排除格；胜负条件（任务一句话、坚持秒数、需到达人数、区域格、目标 id）；敌方与预置单位（新增 / 复制 / 删除，改 id、形态、阵营、位置、显示名、是否计入全灭、六项属性覆盖）；关卡加成（目标、属性、倍率、加值） |
| 引导步骤 | 新手引导的每一步：文字、推进方式、高亮目标；可以拾取目标、预览 |
| 解锁表 | 每关可用的行为 / 条件 / 目标选择，通关解锁内容；能导出总表 |
| 提示文案 | 机制提示、四层提示 |

几点说明：

- **改回原值就不算改动**：任何数值改回关卡原值后，覆盖会自动删掉。「恢复本关原值」会一次清掉这一页的全部改动。
- **试玩本关（用未保存的配置）**：不用保存就能进关卡试改好的数值。从关卡顶部的「返回配置器」回来，没保存的修改都还在。
- **敌人的指令不在这里改**：敌人的指令（rules）跟着单位原样保留。新增的单位使用该形态的默认指令。
- **第七关只读**：第七关数据冻结，所有页都只读。

## 数值策划：配置完发给程序

1. 选关，在各页修改，用「试玩本关」验证手感。
2. 在顶栏「配置包备注」里写上作者和改了什么，例如：`张三：第5关预算 6→8，W1 生命 130→150`。
3. 点「**导出配置包**」。配置会先自动校验，不通过时状态栏写明原因，并且不会导出。
4. 文件生成在工程旁边的 `AI版本/exports/关卡配置包_<日期时间>.json`。点「打开导出文件夹」就能找到它，把这个文件发给程序。

不需要按「保存」，导出的是配置器里当前的全部内容，没保存的修改也会包含进去。

## 程序：配进正式游戏

1. 打开配置器，点「**导入配置包**」，选收到的文件。
2. 确认框会列出导出时间、备注，以及每关改了哪些项（出场、敌方与预置单位、胜负条件等）。校验不通过的配置包不能导入。
3. 点「确认导入」后，配置器会：
   - 先把原来的 `teaching.json` 备份到 `exports/备份/`
   - 写入新内容并重新加载
   - 在 `docs/CHANGELOG.md` 记一行
4. 然后在 `godot/` 目录运行检查：
   - `python tools/validate_data.py`
   - GUT 全量测试
   - `run_playtests -- --check`。数值改了，推荐方案的结果很可能跟着变；确认是有意的改动后，用 `-- --update-baseline` 更新基线。
5. 提交 `godot/data/teaching.json`（和 CHANGELOG）到 git。

### 可选：把数值写进关卡文件

```
python tools/bake_teaching.py --dry-run     # 先看会改哪些
python tools/bake_teaching.py               # 写入关卡配置项（出场 / 部署区 / 单位 / 胜负 / 加成）
python tools/bake_teaching.py --all         # 连同可用指令 / 通关解锁 / 提示文案
```

写入关卡文件后，这些覆盖会从 `teaching.json` 中移除。引导步骤保留，第七关跳过。不做这一步也可以直接发布。

## 注意

- 配置包里是完整的 `teaching.json` 内容，导入会**整体替换**本地的 `teaching.json`。程序本地也改过配置时，先导出自己的版本备用，或者让策划在最新工程上配置。
- 关卡编号、地图尺寸、障碍、路线、敌人指令不在配置器里改。

## 1. 画布、风格与排版

全界面设计坐标 1920×1080，章节世界图独立为 3840×1080。窗口缩放由程序现有居中换算统一处理。低饱和暗调、西方神秘学与炼金术、克制骨质装饰；背景可有油画纹理，控件保持干净边缘。不得出现非文字的水印、Logo、签名，不使用任何现有游戏画面元素。

色板：底 #120A10；面板 #2A1430；次级/禁用 #4A3350；干血红 #7A1E2B；骨白 #E8DCC4；次文字 #B8AA8E；炼金金 #C9A24A；警告 #FF4B3E。hover / 键盘焦点共用金边，pressed 深色内凹，disabled 灰紫并降低文字对比度。中文 NotoSerifSC（项目现有 Regular/Bold OFL 字体），数字 Cinzel；标题 72、弹窗标题 40、分段 26、正文/按钮 26–30、辅助 20 px。字号皆为设计坐标，设置字体倍率由程序应用。

常规文字使用程序标签，不烧进按钮贴图，直接用游戏内NotoSerifSC/Cinzel字体文件渲染，不接受模型仿造字形。游戏名等关键标识按用户要求使用原创艺术字，计为独立图像素材；游戏名上部80%突出光洁炼金金属、珐琅与圣器工艺，血肉/骨质仅保留最底端15–20%；用户允许必要时将Logo融入艺术字。本版不另加独立Logo。艺术字已导出独立game_title_art.png切片。动态值仍由现有strings/数据驱动，没有新增业务接口。

## 4. 切片与 manifest 契约

遵循10 §1.2：schema_version=1，screen，design_size=[1920,1080]，elements按从后向前的绘制顺序排列；kind仅 image / ninepatch / button / icon / toggle / slider / text_style。rect=[x,y,w,h]用全局设计坐标；text_rect是元素内部坐标。所有file/states路径相对当前manifest目录，可用 `../common/` 复用，必须最终落在assets/ui内。

文件 snake_case，按钮 `_normal/_hover/_pressed/_disabled.png`，开关 `_on/_off.png`。按钮的states四态齐全，框图不含文字，font={family,size,color}。九宫格按左上右下顺序。滑条分轨、填充、把手三个元素，轨/填充kind=ninepatch，把手kind=icon；这样复用既有字段，不发明slider专有接口。开关 kind=toggle，states={on,off}；需程序方在P5确认导入支持。下拉kind=button + 独立箭头icon；弹出选项由程序用公共下拉四态生成。text_style元素只有rect/text_rect/font，真实内容与strings key对应表见各目录TEXT_BINDINGS.md；设计示例值同样写在该表，不新增schema字段。

用户于2026-10-05批准V5整图并授权拆分。本次已交付主界面/错误态/设置浮窗manifest、slices、TEXT_BINDINGS与公共四态。设置manifest仅含浮窗层，底图为展示上下文。preview.json仅记录资源比对样例、真实字体路径和文字绑定，不新增运行接口；实际文字复用strings或动态值。

字体NotoSerifSC / NotoSerifSC-Bold / Cinzel映射项目已有字体文件。资源回拼只豁免实际字形alpha介于0与255的抗锯齿像素，不屏蔽整块文字框或面板。主界面正常/错误态非抗锯齿区域差异为0。设置浮窗原整图的半透明层与直接绘字合成方式，和切片标准alpha-over存在细小差异：严格任意通道不等为2.6414%；排除字形AA仍为2.2206%，未达到严格2%目标；再允许每通道1/255取整误差后为0.2817%，最大非AA通道差5/255。这是明确的资源侧比对容差，不能替代程序方P5的实机验收。批准的整图文件没有改动。

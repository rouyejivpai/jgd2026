## 界面流程
主菜单「开始」→ **一级地图**（`scenes/screens/world_map.tscn`）→「进入区域」→ **区域选关**（原选关界面按区域分屏）→ 关卡。

| 操作 | 结果 |
|---|---|
| 在区域选关点「返回」 | 回到一级地图 |
| 在一级地图点「返回」 | 回到主菜单 |
| 关卡里退出 | 回到这一关所在区域的选关 |
| 用「下一关」跨进新区域后退出 | 回到新区域的选关 |

**一级地图**
- 地图按窗口高度等比缩放，居中放在详情面板左侧。
- 每个区域有一块热区和一个名牌（区域名 + 已通关数 / 关卡数）。
- 未解锁的区域压暗并带锁，全部通关的带勾。
- 点一下选中（金环）；再点已选中、已解锁的区域，直接进入。
- 右侧详情：第 N 区、区域名、进度，以及一行状态（下一关 / 本区已全部通关 / 通关「第 N 关 关名」后解锁），下面是本区关卡列表和各关状态，最下方是「进入区域」。

**区域选关**
- 标题显示区域名，只显示本区的节点和区域地图，跨区域的连线不画。
- 默认选中本区最新可挑战的关卡；本区节点放得下时保证全部可见。

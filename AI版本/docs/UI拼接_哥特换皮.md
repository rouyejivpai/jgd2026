来源：用户交付的 `01.zip`（C01资产 D01–F02 切图 + C02参考 选关 / HUD / 对话整图）、`E11-8.png` / `E12-8.png`（出场卡前片 / 后片）、`D06-8.png`（关卡节点图标）、主界面整图 `1792332618.png`。

## 1. 做法

- 切图入库：`python -I tools/import_gothic_ui.py <01解压目录> <E11> <E12> <D06> <主界面图>` → `godot/assets/ui/gothic/`。脚本里写了三处修补（1921 宽裁 1920、对话框底部透明行补齐、对话框里烘进的「示例文本」抹掉）。
- 坐标：切图在参考整图里的位置用模板匹配量出，直接写成设计坐标（1920×1080），不走 `ui_fit_reference.py`。
- 覆盖层：`assets/ui/<screen>/skin_overrides.json` 叠在原 `manifest.json`（拟合产物，不手改）之上，`apply_ui_manifest.py` 合并：按 id 覆盖字段（null 删字段）、`_remove` 删除、新元素 `_after` / `_before` 定序。想退回旧皮：删掉 skin_overrides.json 再跑 `python tools/apply_ui_manifest.py chapter battle_hud main_menu`。
- 对话是新建的 `assets/ui/dialogue/manifest.json`（原来是代码里写死的版式）。
- 改完切图或坐标：`Godot --import` → `python tools/apply_ui_manifest.py chapter battle_hud dialogue main_menu`。
- 截图：`take_screenshots.gd -- --screen=main_menu | region | dialogue`（新增 dialogue 模式，`--story=<id> --line=N`），局内 `--levels=<id> --phase=deploy`。

## 4b. 第三批（2026-10-19）：UI 动效、结算演出、分数提示、出框排查

参数全部在 `data/ui_motion.json`（新增 `state_ease`、`panel_in`、`toast`、`result` 四档）；截图 `--no-motion` 时一律直接显示终态。

| 项 | 做法 |
|---|---|
| 状态切换缓动 | `UiKit.ease_to`：选关节点选中 / 非选中（放大与名牌反向缩放同步、图标调色）、出场卡悬停抬起 / 落下、固定槽位卡已放置变淡 |
| 弹窗出现 | `UiKit.pop_in`：任务、机制说明弹窗、角色详情侧栏、结算框体淡入并从 0.97 放大到原样；提示栏每条淡入 |
| 结算演出（胜利） | 框体淡入 → 四行计分（人数 / 指令要素 / 信标 / 用时，各为「数量 × 系数」）逐行出现，数字从 0 涨到该项分数（expo out，越接近越慢）→ 右侧斜 14° 盖章（AI 生成的暗红印框，从 2.6 倍落下 + 轻震），章内是综合分与「新纪录 / 最佳 N」→ 完成时间、存活单位、解锁打字机逐字出现，超出正文区时自动滚到底 → 按钮淡入。演出中点击面板直接跳到终态 |
| 结算演出（失败） | 框体淡入 → 时间、存活、原因、最后一击打字机 → 按钮 |
| 分数记录与提示 | 存档本来就保存每关最好成绩的完整明细；新增 `SaveManager.best_score_detail`、`Scoring.tip_text`。局外悬停选关节点的综合分标签、或详情面板的「状态 · 已通关 · 综合分」，显示四项构成。全部界面的悬停提示统一为深底细银边（`UiKit.ui_theme` 加载时补 TooltipPanel / TooltipLabel） |
| 结算按钮样式 | 修复：按钮动效（ButtonMotion）在结算按胜负换主题变体前就接管了样式，动效开启时按钮会变成默认红块；新增 `ButtonMotion.recapture()` 在换变体后重新取样式 |
| 出框排查 | `take_screenshots.gd` 加 `--scan-overflow`：每次截图后列出不在滚动遮罩里、字宽 / 行高超出文字区或超出视口的 Label 与按钮。扫了主界面、设置、确认框、对话、一级地图、区域选关，以及 3 个关卡的 11 种局内状态（选中己方 / 敌方、任务、机制、提示、推荐、胜利、失败、校验、信标、添加指令、两条件），共 34 个画面；只发现角色详情属性格「9（+1 关卡加成）」超宽。已改为格内短式「9（+1）」+ 悬停看完整说明，数值格再包一层自动往返滚动兜底 |

## 4c. 第四批（2026-10-19）：弹窗滑入、结算跳过、转场

| 项 | 做法 |
|---|---|
| 弹窗滑入规则 | `UiKit.slide_in`（参数 `ui_motion.json` 的 `slide_in`）：窗口宽或高 ≥ 屏幕 90% 时从最近的屏幕边整体滑入（竖向铺满 → 左 / 右，横向铺满 → 上 / 下，都铺满 → 沿长边）；不铺满但贴着屏幕边（≤ 24 像素）时从贴着的边滑入，几条都贴时取与窗口长边平行的那条；上下左右都不沾的浮窗从下方 40 像素缓动滑入并淡入。滑入途中界面重新排版时以新位置为终点；容器里的节点改为淡入 + 轻微放大。遮罩 / 压暗层只淡入 |
| 已接入的窗口 | 角色 / 敌人侧栏（竖向铺满，贴哪边从哪边进）、剧情对话框（横向铺满贴底，连立绘从下进）、信标边栏（贴底）、任务 / 机制说明 / 提示 / 推荐弹窗、开始校验面板、结算框、设置浮窗、新游戏确认框、引导说明框（每步）、添加指令列表；提示栏每条淡入 |
| 结算跳过 | 演出中任意处点击（含按钮所在位置，按钮在演出结束前不响应）或按确认 / 取消键，直接跳到结束画面 |
| 转场「菱晶碎裂波」 | 取代黑幕：切换前截下旧画面盖在最上层并立即换场景；旧画面被切成 45° 菱晶，从最近一次点击处（无点击时为屏幕中心）向外一圈圈收缩到各自格心消失，收缩中的菱晶边缘先烧成暗红、再亮成银白，新界面从下面露出。0.55 秒，逐帧推进（单帧最多 1/30 秒，新场景加载卡顿不会把动画跳过）。`assets/shaders/transition_shatter.gdshader`，参数 `ui_motion.json` 的 `transition`；截图 `--no-motion` 时直接切换。连拍见 `docs/screenshots/gothic/transition_frames.png` |

测试：侧栏、校验面板、确认框三个布局测试在检查摆放时临时关闭动效（只查终点位置）。

## 4e. AI 切图按真人风格重绘（2026-10-20）

用户：真人设计的切片几乎没有实体描边，形状靠层层叠叠的半透明图层堆出来，这种平面设计感要统一。

## 3. 新机器首次验证（在 `godot/` 目录内执行）

```bash
# 1. 生成 .godot 缓存，暴露解析错误
Godot_v4.7.2-stable_win64_console.exe --headless --path . --import

# 2. 数据校验 —— 应输出“数据校验通过”
python tools/validate_data.py

# 3. 全量测试 —— 应为 Tests 198 / Passing 194 / Pending 4 / exit 0
Godot_v4.7.2-stable_win64_console.exe --headless --path . -s addons/gut/gut_cmdln.gd -gdir=res://tests -ginclude_subdirs -gexit

# 4. 运行游戏
Godot_v4.7.2-stable_win64_console.exe --path .
```

三项结果与上面一致，就说明环境正确。

> 中文路径下，`--path .` 在项目目录里执行最稳。

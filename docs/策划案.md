# 玩法规则

## 3.1游戏主玩法

在《人工神灵》中，玩家需要扮演一位试图完成炼金术终极目标的炼金术士，她计划创造具有智慧的人工生命，不过，她很快发现创造出来的生命似乎只懂得执行指令，还没有太多智能，偶然的契机，她发现可以通过训练这些生命来使得它们的智能在某个临界点涌现出来，她尝试了几次，发现人工生命执行指令的能力确有提升，于是，她就在这个方向不断努力下去，希望能创造出真正的生命。

风格为西方神秘学/炼金术魔幻风格

示意如下

![img001.png](../_refs/media/img001.png)

玩家需要完成每个关卡的目标，例如全歼敌人，到达指定位置，保证某物存活直到倒计时结束，摧毁敌方核心等等。

为了完成目标，玩家初始会在场上拥有一些单位，它们会严格按照玩家编制的指令行动，玩家所需要做的就是根据关卡需求，灵活判断局势，编制合适的指令，按下开始键，过关，解锁新指令和新的地图机制等等。

### 3.3.2指令执行细则

指令具有优先级，或者说是执行顺序，放置于上层的指令会先执行，而放置于下层的指令会后执行，这是指令的顺序结构。

例如，1位置的指令无条件 停火 2位置的指令为视野中出现敌人时，开火，那么当视野中出现敌人时，先执行1停火，再执行2开火，则最终效果就是有敌人时开火。

指令可以有多个条件和多个行为，不过，相同类型的行为只能有一条，例如你不能在一条指令中同时写开火/停火，这是自相矛盾的被禁止的行为。

指令的条件可以有与（同时满足）或（满足其中1项）的区别。

## 3.6结算规则

通关后，有三个角度评判玩家的表现。

指令复杂度=（行为数量+条件数量）*系数

信标数量=信标数量*系数

所用时间=所用时间*系数

将三个指标相加，就是玩家的最终评价，越低越好。

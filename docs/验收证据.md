## 5. 括号里的数字怎么重新统计

数字是**跑出来的**，不是手写的（我手写第一版就把两段写错了）。重新统计：

```python
import re
lines = open(r"D:\jgd2026\_logs\smoke.txt", encoding="utf-8", errors="replace").read().splitlines()
cur, secs = None, []
for ln in lines:
    s = ln.strip()
    if s.startswith("--") and s.endswith("--") and len(s) > 4 and s.strip("-").strip():
        cur = {"name": s.strip("-").strip(), "pass": 0, "fail": 0}
        secs.append(cur); continue
    if cur is None: continue
    if "[PASS]" in s: cur["pass"] += 1
    elif "[FAIL]" in s: cur["fail"] += 1
print(len(secs), sum(x["pass"] for x in secs))
for x in secs: print(f"  {x['pass']:4d}  {x['name']}")
```

> **注意**：分段标题的收尾 `--` 前**不一定有空格**（例如 `…（含拖拽指示线）--`），
> 用「`--` + 空白 + `--`」去匹配会**漏掉整段**，并把它的用例数并进上一段。
> 我第一版就是这么错统计的。
